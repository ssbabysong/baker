# 面包物语 · Bakery Days 🥖

一个简笔画风格、极简的烘焙配方 app——像在模拟经营自己的面包小店。

画风：日式街角面包店——生成色的纸、可可色单线、蜡笔质感的木头 / 瓦灰 / 藏青暖帘色块（故意和线条错开一点，像手工套色印刷），朱红小印章做点缀，日期数字用打字机字体。

字体：小赖字体（Xiaolai SC，SIL OFL 1.1），子集化后随 app 一起提供（`fonts/shopfont.ttf`，授权见 `fonts/OFL.txt`）。

## 功能

| | |
|---|---|
| **导入配方** | 整段粘贴食谱文字，自动认出「材料 + 用量」和「步骤 + 时间」（中英文都行），导入后可再改；也能手写、导入 .txt / .json |
| **烘焙模式** | 称料打勾清单（称完自动折叠）、份量 ×0.5 / ×1 / ×1.5 / ×2；发酵和烘烤一键计时；可以同时烤好几炉，首页一炉一台烤箱；计时期间屏幕常亮 |
| **计时提醒** | 时间到会响铃 + 震动 + 系统通知；计时器记录的是"结束时刻"，关掉 app 再回来也准 |
| **边做边改** | 烘焙中随时「改配方」；出炉时列出改动，选：更新原配方 / 另存为新配方 / 只记在这一次 |
| **出炉记录** | 拍照、打分、写笔记；首页「作品墙」是拍立得，「日历」页在烘焙过的日子画上那款面包，每一炉是一页烘焙日记 |
| **吐司店长** | 一片系着藏青头巾、会挥手的吐司站在店门口，烘焙时守在烤箱旁边等你，时间到会跳起来叫你 |
| **经营感** | 店名可改，按出炉次数升级 8 级：周末小推车 → 私房小铺 → 熟客小店 → 街角面包店 → 排队小店 → 两层小楼 → 露台面包店 → 旗舰面包店；配方架上每款面包有价签（随机定价，可改，人民币 / 美元） |
| **小组件** | 我的店面（小）、配方架（中 / 大）、烘焙日历（中 / 大），点了直接跳到对应页面 |
| **中英文** | 设置里切换中文 / English |
| **内置配方** | 放在 `catalog/recipes.json`，app 启动时从 GitHub Pages 拉最新版，不用发版就能更新 |
| **其他** | 白纸 / 黑板两种外观，离线可用，可安装到手机主屏幕，数据可导出备份 |

## 运行

纯静态网页（PWA），不需要构建：

```bash
npm start        # 打开 http://localhost:8080
npm test         # 配方解析器的单元测试
```

部署到任意静态托管（GitHub Pages、Netlify、Vercel…）即可，在手机浏览器里打开后「添加到主屏幕」就是一个 app。
通知和离线缓存需要 HTTPS（或 localhost）。

## 内置配方（不用发版就能更新）

内置配方都在 `catalog/recipes.json`。app 里自带一份，启动时（之后每 12 小时最多一次）会去
`https://ssbabysong.github.io/baker/catalog/recipes.json` 拉最新的一份，所以**改内置配方只要改这个文件、推到 GitHub**，一两分钟后 GitHub Pages 更新，用户下次打开 app 就会拿到，不用重新上架 App Store。

改的时候：

1. 在 `recipes` 里改或加一份配方，中文写在 `zh`、英文写在 `en`（材料和步骤条数要一样，一一对应）。
2. **改了哪份，就把那份的 `rev` 加 1；文件最上面的 `version` 也加 1**（app 只认比手上更大的 `version`）。
3. 新配方给一个新的 `key`（小写字母、数字、横线），以后就别再改它。
4. 想让某份不再给新用户上架：把它的 `key` 加进 `removed`（已经在用户架上的不会删）。
5. 推之前跑一下 `npm test`，会检查格式（key 重复、缺字段、中英文条数不一致……）。

用户那边会发生什么：

- 新的 `key`：自动上架；用户自己删掉过的不会再放回来。
- 用户没改过的配方：自动换成新版，价签和做过的记录都保留；切换语言也会跟着换。
- 用户改过的配方：不动，配方页上出现「店里有新版的这款配方」，用户可以选「换成新版」或「留着我的」。
- 没网、GitHub 打不开、或者文件格式坏了：继续用手上那份，什么都不会坏。

> 如果以后改了文件结构，老版本 app 看不懂，就把 `schema` 改成 2——老版本会直接忽略新文件，继续用自带的。

## 用 Xcode 装到 iPhone

`ios/` 是用 [Capacitor](https://capacitorjs.com) 包的原生壳，里面跑的还是这套网页。原生版的计时提醒用系统本地通知，锁屏、关掉 app 也会准时响。

需要一台 Mac，装好 Xcode 和 Node.js（18 以上）：

```bash
git clone https://github.com/ssbabysong/baker.git && cd baker
git checkout claude/gifted-bardeen-ba7dmj
npm install
npm run ios      # 拷网页文件 → 同步进 iOS 工程 → 打开 Xcode
```

在 Xcode 里：

1. 左边点最上面的 **App**，选 **Signing & Capabilities**，Team 选你的 Apple ID（没有就点 Add Account 登录，免费账号也行）。
2. 如果提示 Bundle Identifier 被占用，把 `com.ssbabysong.bakerydays` 改成别的，比如加上你的名字。
3. 用数据线连上 iPhone，顶部设备选你的手机，点 ▶︎ 运行。第一次要等 Xcode 下载依赖。
4. 手机上第一次运行会提示不受信任：**设置 → 通用 → VPN 与设备管理**，信任你的开发者账号；iOS 16 以上还要在 **设置 → 隐私与安全性** 里打开 **开发者模式**。

改了网页代码以后，再跑一次 `npm run ios`（或 `npm run build:www && npx cap sync ios`），然后在 Xcode 里重新运行。
免费 Apple ID 签的 app 7 天后会过期，到时候连上电脑在 Xcode 里再点一次运行就好。

## 结构

```
index.html            外壳 + 手绘抖动滤镜
css/style.css         全部样式（墨线、纸色、歪歪扭扭的边框）
js/app.js             路由和所有页面
js/parser.js          食谱文字解析
js/store.js           IndexedDB 存储（配方 / 出炉记录 / 照片 / 进行中的烘焙）
js/timers.js          计时、铃声、通知、屏幕常亮
js/sketch.js          所有简笔画 SVG
js/samples.js         首次打开的示例配方
icons/                app 图标（icon.svg；node icons/render.mjs 重新生成 PNG）
sw.js                 离线缓存 & 点通知回到计时页
```

## 已知限制

- 数据只存在当前设备浏览器里，换设备请用「店务 → 导出备份」。
- 网页 app 在后台被系统挂起时，计时提醒可能要等回到 app 才弹出（iOS 尤其明显）；装到主屏幕 + 打开通知权限效果最好。如需锁屏后准时提醒，下一步可以用 Capacitor 打包成原生 app，改用本地通知。
