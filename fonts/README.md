# 字体文件

`xiaolai.ttf`（小赖字体，见下）是全 app 的中文字体（标题也用它，靠描边加粗），网页版和 iOS App 用的是同一份。

`shopfont.ttf` 是「也字工厂小石头」，作为后备字体（小赖字体里缺的字）。

- 版权：也字工厂 / 深圳仪品信息技术有限公司（www.yefont.com）
- 授权：多家字体站依据作者声明标注为「免费商用」；字体文件内的说明写着「本字体由深圳仪品信息技术有限公司制作 需授权请联系了解授权协议」。用于 app 内嵌之类的用途，建议向也字工厂确认。

## 小赖字体

`xiaolai.ttf` 是「小赖字体」（Xiaolai SC 3.11），网页版和 iOS App 都用它；原生底部菜单和桌面小组件也用它。

- 来源：https://github.com/lxgw/kose-font （作者 LXGW，衍生自濑户字体）
- 授权：SIL Open Font License 1.1，全文见同目录的 `OFL.txt`。允许嵌入 App 并随 App 分发，不能单独售卖字体文件。
- 做了子集化（3.3 MB）：保留 GB2312 全部汉字、app 源码里用到的所有字、日文假名、拉丁字母和常用符号，其余字落到小石头 / 系统字体。字体名称未改。
