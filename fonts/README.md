# 字体文件

`shopfont.ttf` 是「小赖字体」（Xiaolai SC，3.11 版），app 的标题、正文、iOS 小组件和底部菜单都用它。

- 来源：https://github.com/lxgw/kose-font （作者 LXGW，衍生自濑户字体）
- 授权：SIL Open Font License 1.1，全文见同目录的 `OFL.txt`。允许嵌入 app 并随 app 分发，不能单独售卖字体文件。
- 为了减小体积，文件做了子集化：保留 GB2312 全部汉字、app 源码里用到的所有字、日文假名、拉丁字母和常用符号（约 8800 字），其余字落到系统字体。字体名称未改。
